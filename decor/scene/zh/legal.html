销售条款

1. 卖方与买方

本条款适用于法律声明中所列发布者（“我们”）通过本网站向任何成年人（“你”）出售的每一束花。 为花束付款即表示接受本条款于购买当日的版本。本条款有多种语言版本，以法语版本为准。

2. 花束是什么

花束是一件独一无二的数字艺术作品：以矢量图形绘制的花朵，插在花瓶中，以非同质化代币（NFT）的形式记录在 Base 网络上。购买前，每束花的页面都会显示其名称、花瓶、花枝数量和价格。

一束花自铸造之日起能活三个月：它会绽放、轻摆，倒计时显示剩余时间。之后，它会凋谢，并永远保持凋谢、静止的模样。 这是作品的一部分，而非瑕疵。

花束是一件收藏品，不赋予任何获取收入或份额的权利。

3. 花束归你所有

持有其代币，即拥有这束花：你可以在任何地方展示、保存、赠送或转售，无需其他手续。如同一幅画， 购买花束并不转让画作的著作权：制作并出售其复制品或周边商品不在许可范围之内。

4. 价格

价格以 ETH 标示，不含增值税（依据法国《税法通则》第 293 B 条，免征增值税），并在购买前显示在花束上。旁边以欧元或美元显示的金额，是按 CoinGecko 提供的当前汇率换算的同一价格；你支付的是 ETH 价格。Base 网络的手续费（“gas”）由你的钱包另行加收， 支付给网络，而非我们。

5. 下单与付款

你在本网站上用自己的钱包付款，通过 Seaport 完成。Seaport 是我们的花束所上架的 OpenSea 平台所用的协议。 付款前，你需勾选一个方框，要求立即交付（见第7条），然后确认；你的钱包随即显示确切金额，在钱包中确认即构成 负有付款义务的订单。已在网络上确认的转账无法撤销。

你须自行负责你的钱包、钱包密钥以及用于购买的地址。我们从不保管你的密钥或你的资金。

6. 交付与收据

网络一经确认，花束即在同一笔转账中转入你的钱包。随后，网站会提供一份可下载的收据，确认本次购买、 价格、转账以及你提出的立即交付请求。该转账在 Base 网络上的记录亦可作为购买凭证。

7. 撤回权

如果你是欧盟境内的消费者，通常享有自远程购买之日起 14 天的撤回权。花束属于不以有形载体提供、 并即时交付的数字内容：付款前，你明确要求立即交付，并确认你因此失去撤回权（法国《消费法典》第L221-28条第13项； 欧盟第2011/83号指令第16条(m)项）。

隐私政策

数据控制者为法律声明中所列的发布者。我们尽可能少地收集数据， 且绝不用于对你进行画像分析。

处理哪些数据、出于何种目的、依据何种法律基础

  • 连接数据（IP 地址、浏览器、所访问的页面）：由我们的托管商 Cloudflare 保存在其技术日志中， 用于提供网站服务并防止滥用。法律基础：我们维持网站正常、安全运行的正当利益。
  • 你所在的国家：每次访问时由 Cloudflare 根据你的 IP 地址推断，用于以你的语言显示网站， 并以你的货币显示价格。该信息即时使用，从不保存。法律基础：我们让你能读懂网站的正当利益。
  • ETH 汇率：为以你的货币显示金额，你的浏览器会向 CoinGecko（api.coingecko.com） 查询当前汇率；CoinGecko 会看到你的 IP 地址。法律基础：我们显示最新金额的正当利益。
  • 你的钱包地址：在你购买或关联钱包时读取，用于完成购买或展示你的花束。法律基础：合同。 Base 网络上的转账是公开且永久的：我们和任何人都无法将其删除。

Belai Bureau 使用许可

Belai Bureau 是一款适用于 Windows 10 和 11 的免费软件，可在你的桌面上展示你所关联的钱包持有的花束。 我们授予你免费、个人、非独占的许可，以安装和使用本软件。你不得出售本软件，也不得分发经修改的副本。

它如何处理数据：它会在你的电脑上保存一个代表这台电脑的随机代码、你所关联的钱包地址以及你的设置。 它会向 Base 网络（mainnet.base.org，由 Base 运营）查询你的钱包持有哪些花束，并在你关联钱包时在浏览器中打开本网站。 它不向我们发送任何数据，也不做任何统计。

本应用按“现状”提供。卸载它（Windows 设置 › 应用）即可删除应用及其设置。
